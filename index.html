Status is probed every 60 seconds from the edge VPS and published at status.dreeko.space. This page is hosted on GitHub Pages on purpose: every service above is proxied through that one VPS, so a status board living beside them would go dark in exactly the outage worth reporting.

Probes run from inside the edge, so they exercise the proxy, the private network hop and the application — but not public DNS. If you are reading this, that part works.
